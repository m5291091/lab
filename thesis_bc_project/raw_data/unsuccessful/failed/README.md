# raw_data/unsuccessful/failed

**非 OOM・非早期打切りの「その他ハード失敗」** を分類するカテゴリ。

現時点で該当する生データは **なし**。本アーカイブで確認された失敗は次の 2 種のみ:

- OOM（メモリ不足による強制終了, exit 137） → `../oom/`
- early_terminated（比較不一致による fail-fast 早期打切り） → `../early_terminated/`

将来、上記いずれにも当てはまらないハード失敗（例: セグフォルト、I/O エラー、
不正入力による異常終了）が生じた場合はここに分類する。成功データは混在させない。
